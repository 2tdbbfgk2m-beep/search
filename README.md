# Search

用于长期存放研究相关资料、论文笔记、想法、实验记录与参考资料。

## 目录结构

- `papers/`：论文与论文阅读记录
- `notes/`：研究笔记、概念梳理、会议/讨论记录
- `ideas/`：研究想法、假设、待验证方向
- `experiments/`：实验设计、结果记录、复现说明
- `references/`：外部资料、链接索引、参考文献整理

## 使用约定

- 尽量使用 Markdown 保存可读笔记。
- 论文笔记建议以 `年份-作者-短标题.md` 命名。
- 实验目录建议包含目标、配置、结果和结论。
- 尚未成熟的想法先放入 `ideas/`，确认后再迁移到正式研究记录。
